Passkey Vault · iOS · milestone v1.0

Every screen, in both appearances

Native iOS structure, brand colour. Each phone below is rendered from the real ios/brand/tokens.json values — the same file that generates the asset catalog — so if a colour looks wrong here, it is wrong in the app. Light and dark are shown as a pair throughout, because every one of these tokens resolves differently between them.

The palette these screens are built from

Ratios are measured against surface/default in the matching appearance. The light values are not the brand values: every one was derived in OKLCH — hue and chroma held, lightness reduced — until it reached 4.5:1. The raw web palette is tuned for dark chrome and fails on a near-white iOS ground.

accent/on-accent exists because a test failed. The accent has two jobs that pull opposite ways in dark mode: it must be lightened to stay readable as text on a dark surface, which necessarily makes a white label sitting on top of it worse — white measures 3.34:1 there. So the label is mode-aware: white knockout on light, near-black knockout on dark. docs/UI-DESIGN.md defines this as a single-valued Primary content #FFFFFF, which is correct for the web's always-dark surfaces and incomplete for iOS.

Onboarding — three steps

Welcome → Server → AutoFill, with dots. Apple's guidance argues against gating on setup (“provide reasonable default settings so most people can immediately start”), so the server step is pre-filled and skippable rather than a prompt, and the AutoFill step offers Later. The shape is a paged flow; the content refuses to block.

Decisions this leaves open

Recorded rather than quietly resolved, because each needs a call that isn't mine.

Logo vs. palette The mark's orange is #FD5F36; the accent is #C94F2A. Pulling tokens toward the logo makes contrast worse, so either the logo stays deliberately its own thing, or it gets redrawn. There is no vector source, so redrawing is real work.
Item-type iconography Six types need to be distinguishable at a glance in a dense list. Not specified here — it is the one genuinely visual problem left, and the place a reference library would actually earn its cost.
Dynamic Type at AX5 Every screen above is drawn at the default size. Phase 37's matrix ran at 390pt instead of the specified 375pt, and that substitution is still outstanding.
