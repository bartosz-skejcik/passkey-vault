`totp-rs` 5.7.2 API surface actually needed here (from docs.rs, WebFetch-verified during research):
```rust
use totp_rs::{Algorithm, Secret, TOTP};

// Algorithm::SHA1 | Algorithm::SHA256 | Algorithm::SHA512

// Secret::Encoded(String) wraps a base32 string; .to_bytes() -> Result<Vec<u8>, SecretParseError>
let secret_bytes = Secret::Encoded(secret_b32.to_string()).to_bytes()?;

// TOTP::new(algorithm, digits, skew, step, secret_bytes) -> Result<TOTP, TotpUrlError>
// skew=1 is the standard one-period clock-drift tolerance.
let totp = TOTP::new(Algorithm::SHA1, 6, 1, 30, secret_bytes)?;

// TOTP::generate(unix_time_seconds: u64) -> String — the ONLY time-taking method
// this module may call. `generate_current`/`check_current` read the OS clock via
// SystemTime::now() internally, which is unimplemented on wasm32-unknown-unknown
// and panics the moment it actually executes in the browser (RESEARCH.md Pitfall 1)
// — a successful `cargo build --target wasm32-unknown-unknown` does NOT prove this
// was avoided; it must be verified by reading the diff, not by grep or build exit code.
let code: String = totp.generate(unix_time_seconds);
```
