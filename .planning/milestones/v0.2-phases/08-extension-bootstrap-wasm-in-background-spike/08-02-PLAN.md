  <action>
    Define and export `type SessionStorage = { get(key: string): Promise<Record<string, unknown>>; set(items: Record<string, unknown>): Promise<void> }` and `roundTripSpike(storage: SessionStorage): Promise<{ survived: boolean; ok: boolean }>` in `extension/lib/crypto/vault-session.ts`. The storage dependency is injected, never imported globally — this is what makes the file's core logic testable without any browser mock and is also what keeps D-05's invariant enforceable by construction: this file has no code path that can reach a persistent storage area, because it never references one by name at all, only the generic injected interface.
