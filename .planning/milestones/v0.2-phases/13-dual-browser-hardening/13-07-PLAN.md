<objective>
Extend 13-06's server-origin ceremony from unlock-only to FULL SIGN-IN (Bartek's explicit mandate, 2026-07-18: "Zrób teraz" + the button must exist on the login screen). After a browser restart the popup lands on sign-in (storage.session wiped) — today that always means retyping the master password on both browsers. This plan reuses the v0.1 web passkeyLogin (server-verified WebAuthn assertion issuing a session token + returning prf_wrapped_uk) inside the existing ExtUnlockBridge ceremony window, relays {token, prf, blob} over the already-hardened 13-06 channel, and has the background persist the token + unwrap the UK — one passkey gesture from cold popup to unlocked vault.

Also closes the 13-02/13-06 UX seam Bartek hit live: the Firefox EnrollExtPasskeyPrompt advertises the permanently-impossible ext-scoped passkey; on Firefox it must instead point at the server-passkey path.
</objective>
