<objective>
Implement the background service worker's autofill orchestration: match saved items to the active frame's origin, decrypt exactly the one selected item in `pv-wasm`, generate the live TOTP code, and deliver plaintext field values to the *specific* target frame — with the origin/frame gate re-checked at fill time, never merely at match time.

Purpose: This is the crypto boundary for the whole phase (10-CONTEXT.md D-02, ARCHITECTURE.md Anti-Pattern 1). Every zero-knowledge and cross-origin guarantee the phase makes is enforced here, in the one context that holds the User Key. It exercises Phase 9's messaging pipeline end-to-end on a read-heavy, lower-stakes operation before Phase 12's passkey provider raises the stakes — the deliberate de-risking order 10-CONTEXT.md records.
Output: `background/autofill-match.ts` (three handlers) + tests, and the three `autofill.*` cases wired into `router.ts`.
</objective>

<data_flow_note>
Read 10-01's `<architecture_note>` first. The popup-driven flow this plan implements:

- **autofill.match** (popup→bg): resolve the active tab via `browser.tabs.query({active,currentWindow})` → `resolveFillTarget()`. If restricted/unreachable, return `{pageState}` with no matches. Else `browser.tabs.sendMessage(tabId, {kind:"content.detect"}, {frameId:0})` to ask the content-relay which field families are present (`DetectedFields`), then filter `getDecryptedItems()` through `itemMatchesOrigin()` for each detected family. Return metadata only (`AutofillMatch[]` — id, label, masked hint), never secrets.
- **autofill.fill** (popup→bg): re-resolve the target frame from scratch (do NOT reuse the match-time target), re-run `itemMatchesOrigin` for the requested `itemId`, decrypt that ONE item, `browser.tabs.sendMessage(tabId, {kind:"content.fill", values}, {frameId})`. Return `{ok}` — never the values.
- **autofill.totpCode** (popup→bg): the ONE path returning a secret-derived value to the popup, because the UI-SPEC's "Kopiuj kod" writes the clipboard from the popup. Derive fresh, return `{code, secondsRemaining}`.

If the content-relay does not answer `content.detect` (not injected on this page, or a restricted page), treat it as `pageState: "unreachable"` — never fabricate detection results.
</data_flow_note>

## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| background ↔ pv-wasm / User Key | The single crypto choke-point; the only decrypt in the autofill path. |
| background → target frame (`tabs.sendMessage {frameId}`) | Plaintext values cross here to exactly one frame; the frame identity is an access-control decision. |
| background → popup (`autofill.*` responses) | Metadata + (only for TOTP) a derived code; never a stored secret or the User Key. |
