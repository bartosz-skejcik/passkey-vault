<objective>
Wire a supply-chain tripwire (`cargo audit` + `cargo deny`) into this project's toolchain, and
exact-pin the Rust toolchain plus the watch-list crypto/auth crates the v0.3 codebase sweep flagged
(SEC-03).

Purpose: CODEBASE-GAPS.md Top-5 #5 flagged native OpenSSL (via `webauthn-rs`), single-maintainer
`passkey-rs` (1Password, still at 0.5.0 with no newer release), and a floating `rust-toolchain.toml`
`stable` channel as unreviewed drift risk with no automated check today. Both tools are absent from
this development machine (confirmed this session) and install cleanly via `cargo install`.

Output: `deny.toml` (advisories/bans/licenses/sources policy), an exact-pinned `rust-toolchain.toml`,
exact `=x.y.z` pins for every directly-declared watch-list crate, and a fail-loud
`scripts/check-supply-chain.sh` wrapper — CI wiring itself is explicitly Phase 20's job (QA-01); this
plan only needs the commands to be CI-ready, which a documented shell script already is.
</objective>
