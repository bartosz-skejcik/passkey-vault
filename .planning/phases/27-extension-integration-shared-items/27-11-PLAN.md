| Boundary | Description |
|----------|-------------|
| Server-side revocation <-> a still-unlocked extension session | The client must lose access on its own next poll, without relying on a lock/unlock cycle to force re-derivation — this is the one boundary no earlier plan proved live |
| Member B's capture-confirm write <-> member A's collection-scoped read | The only write-path boundary in this phase with no real-crypto evidence anywhere else — 27-07's own unit suite mocks the encrypt call, so a wrong-key/wrong-scope/wrong-AAD regression there is invisible until this plan's live proof |
