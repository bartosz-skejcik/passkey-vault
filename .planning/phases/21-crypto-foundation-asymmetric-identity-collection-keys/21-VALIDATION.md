## Sampling Rate

- **After every task commit:** Run `cargo test -p pv-core` (fast — no I/O, no WASM build needed for pure-crypto tasks)
- **After every plan wave:** Run `cargo test --workspace` **and** `cargo build -p pv-wasm --target wasm32-unknown-unknown --release` (the real WASM build must stay green with the new crate present — this is the gate that catches a `getrandom`/`rand_core` graph perturbation)
- **Before `/gsd-verify-work`:** Full suite green **and** `scripts/check-supply-chain.sh` exits 0 (picks up the new `deny.toml` watch-list row)
- **Max feedback latency:** 30 seconds
