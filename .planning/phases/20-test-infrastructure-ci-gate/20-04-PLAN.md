## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| GitHub Actions runner (ephemeral VM) <- repository code + PR diffs | A future PR (including from a fork, once a remote exists) runs arbitrary repo code inside CI; the runner has no access to this project's production secrets (none are configured in this workflow) |
| CI workflow YAML <- third-party GitHub Marketplace Actions | Supply-chain trust: `actions/checkout`, `actions/setup-node`, `actions-rust-lang/setup-rust-toolchain` execute with the job's full permissions |
