<objective>
Migrate `ShareDialog.tsx`'s per-person UI from the OLD shared model (one checkbox list + one `ACCESS_LEVEL_VALUES` radio group + one `accessLevel` state, serving per-person selection AND family-wide submission AND both scopes all at once) to the per-row model, for BOTH the folder scope (mint-new only — destination selection is 31-03's job) and the item scope (full grant/update/revoke, since `listItemShares` can return pre-existing shares today), in ONE plan — so no wave leaves either scope on stale markup while claiming the row model is done.

This plan's central structural move, per the plan-check's Blocker 1: the file has never had a genuinely separate family-wide control — `ShareDialog.tsx:1329-1345`'s radio group and its `accessLevel` state are read by `submitItemFamilyWide` and `submitFolderVariant`'s family-wide branch too. CONTEXT.md Area 1's "one place of truth" bar requires that this SAME control (unchanged state, unchanged submit logic) become exclusively family-wide's own — rendered and consumed only when `isFamilyWideSelected`, never shared with or read by the new per-row model. `share.familyWideItemContributorEditNote`'s condition moves with it.

Per Blocker 3, hidden-password's one-time modal and always-visible inline note are re-anchored to the row model in THIS plan (trigger: any row transitioning to `hidden_password`; subject: rows currently at that level) — not deferred to a later wave, so MOD-03 never goes silently false in between. Per Warning 6, the Scale & Scroll Contract's single-scroll-region + pinned-footer restructure lands here too, at the same time as the row list, rather than after it.

Purpose: MOD-01 (the row model itself, both scopes), MOD-03 (the honesty bar stays true throughout the migration, not just at the end).
Output: a dialog that, after this plan, is internally consistent — one source of truth for level in every mode, rows working for both scopes' currently-reachable capabilities (mint-new grant for folders, full grant/update/revoke for items), hidden-password honest on every occasion, and every pre-existing test in the file still green.
</objective>
