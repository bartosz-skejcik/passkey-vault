<objective>
Close SC5's second, genuinely new refusal case — the destination-key-unavailable path that only exists once a dialog can target an EXISTING destination (the fresh-create path can never hit it, since the caller always seals their own copy at creation time). Per RESEARCH.md's own finding, this is reachable only through a narrow TOCTOU window: a concurrent revoke of the caller's OWN access to the destination between dialog-open and submit. This plan drives that window deliberately rather than leaving the failure branch untriggered — an untriggered failure branch is not proven, per this phase's non-negotiables.

This plan also closes Q2's own live proof (an in-place level edit landing atomically alongside a fresh grant in the same submission) and performs the phase's final CI-width acceptance sweep.

Purpose: SC5 (the destination-unavailable case), Q2 (live level-edit proof), phase-wide acceptance.
Output: an honest, deliberately-triggered refusal for a lost-destination-access mid-session; a live proof that a level edit and a fresh grant land atomically together; a green CI-width sweep.
</objective>
