same table that builds the live router (so an ungated route cannot exist and merely go
untested — it functionally never gets registered), plus the automated, permanent version of the
zero-knowledge grep audit every prior plan in this phase ran ad hoc.

family/collection/item surface, and that guarantee is only real once every route built across
Plans 22-01–22-04 is swept in one place — this plan is where that promise becomes falsifiable.
Output: `tests/membership_route_sweep.rs`, a `membership_routes()` cardinality tripwire, and a
permanent automated zero-knowledge boundary check.
