<objective>
Build the reversible half of Phase 25's member-lifecycle surface: an owner can suspend a member's
shared access instantly and without any re-key, and reinstate it exactly as instantly. Prove — live,
through a real request cycle, not by inference — that a suspended member genuinely loses access on
their very next request and regains the SAME unmodified keys on reinstatement.

Purpose: FAM-07 requires suspension to be reversible, immediate, and re-key-free; FAM-09 requires the
access loss to be observable on the very next request. This plan is where both properties become real,
tested server behavior — completing what Plan 25-01's join extension made possible.
Output: `suspend_member`, `reinstate_member`, both routes wired into `mod.rs`, and a live cycle test in
`tests/family_removal.rs`.
</objective>
