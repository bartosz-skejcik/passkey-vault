<objective>
Build the client-side glue between the server's re-key wire contract (Plan 25-03) and the crypto
primitives (Plan 25-02): the API client functions, and the ONE orchestration module,
`families/rekey.ts`, that constructs a real rewrap batch from live server data and real WASM calls —
never a placeholder. This is the module both the remove-member UI and the self-deleting-member account
UI will call, per the orchestrator's resolved decision that both paths share one implementation.

Purpose: KEY-02's client-side half and UX-04's real-item-name resolution both depend on this layer
existing before any dialog can be built. The unit-test blind spot this codebase has already been bitten
by twice (Phase 24) makes the real-WASM regression test in this plan non-optional evidence, not a
nice-to-have.
Output: extended `families/api.ts`/`vault/api.ts`/`crypto/index.ts`, a new `families/rekey.ts`, a new
no-mock `rekey.real-wasm.test.ts`, and every Phase 25 i18n key in `dictionary.ts`.
</objective>
