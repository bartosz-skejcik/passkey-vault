Build the first-run onboarding wizard (UI-04): a full-screen 3-step takeover triggered once, immediately after registration, offering import as step 1 (the real `ImportWizard` from Plan 06-03), a static orientation step 2, and a calm finish step 3 — gated by a per-browser `localStorage` flag so it never re-appears on that browser.
