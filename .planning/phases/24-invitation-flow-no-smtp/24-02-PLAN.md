<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| unauthenticated visitor → GET /api/invitations/{id} | fully untrusted input crosses here — no session, no secret, only a path segment |
| any caller who knows invite_id → POST /api/invitations/{id}/accept | authenticated (a session is required) but pre-membership — CONTEXT.md's own "deliberately low-trust write surface" |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-24-04 | Denial of Service / Repudiation | invitations::accept transaction | high | mitigate | `state.db.begin_with("BEGIN IMMEDIATE")`, matching `vault.rs`'s WR-04 fix for the exact `SQLITE_BUSY_SNAPSHOT` bug class this milestone already found once (commit c94c379) |
