# Existing precedent for the vendoring pattern (copy the SHAPE, never the CONTENTS)
packages/pv-ui/generator/wordlist.ts:1-8 — `EFF_WORDLIST`, 7776 Diceware words. Same vendoring

    Test: parses the hex big-endian, slices the leading 66 bits into six 11-bit indices (2048 =
