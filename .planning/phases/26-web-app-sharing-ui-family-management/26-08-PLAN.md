# Seed-items bulk move (UI-SPEC E2's "seeds ShareDialog's folder-create variant with that personal
# folder's current items pre-selected for a bulk move into the new collection")
For each seed item: decrypt with the caller's own UserKey (existing `decryptItem`, item is
personal so `collection_id` is null), re-encrypt the SAME plaintext under the freshly-generated
CollectionKey via `encryptItemForCollection(newCk, plaintext, newCollectionId, item.id, ???)` —
KEY-03 binds the AAD to the DESTINATION scope; use `expected_revision: item.revision` and submit
via `moveItemToCollection(item.id, newCollectionId, encKey, encData, item.revision)`. A single
seed-item failure must not abort the whole folder creation — the folder itself (with its real name
and real member grants) is the primary deliverable; report which items failed to move via
`share.createFailed`-adjacent inline text without discarding the successfully created folder.
