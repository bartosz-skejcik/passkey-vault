proof reads ONLY revision numbers via `GET /api/sync/shared` (metadata, no ciphertext); SYNC-06's
proof reads ONLY the 409 conflict's `last_editor_email` field (plain JSON, no ciphertext) — both are
genuinely observable without the identity-keypair machinery Phase 26 owns.

live, 2-real-session proof — the milestone's direct application of the recorded v0.2->v0.3 lesson.
