<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| OS clipboard | `copyWithAutoClear()` writes sensitive values (passwords, card numbers, TOTP codes, passkey secrets) to the system clipboard, a shared OS-level resource outside the browser sandbox |
| pv-ui zero-knowledge boundary | Any code entering `packages/pv-ui` is shared by both web and extension — a crypto/key-handling import here would widen the zero-knowledge attack surface to two client surfaces at once |
